What to send someone whose laptop this is

Send them the LanternAgentApp folder with a config.txt containing their own enrollment key from the table above:

LANTERN_SERVER_URL={{ server_url }}
LANTERN_ENROLLMENT_KEY=<their key from the table>

They install Tailscale once from tailscale.com/download (they do not need a Tailscale account — Lantern supplies the key), then double-click Join Lantern.bat. That is the whole thing they ever do.

The enrollment key is single-purpose: it claims one device row. The first machine to use it pins the row to that machine's signing key, so a copied key cannot be used to impersonate the laptop afterwards.
