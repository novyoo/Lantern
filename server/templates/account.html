How a new password is checked

  1. It must be at least 12 characters long.
  2. It is checked against the public list of passwords found in real data breaches — without sending the password anywhere. The password is hashed, and only the first five characters of that hash leave this server. The breach service answers with every leaked hash starting with those five characters, and the matching happens here. The service never learns which password was asked about. That trick is called k-anonymity.

Try passwordpassword to see a real breached password rejected. It is long enough, and it is still refused.
