What Lantern collects, and what it never collects

A rental company can only promise privacy if it is unable to break it. Lantern is built so the server holds nothing it could read even if someone wanted to.

Collected

  • Device ID, rental ID, site ID
  • Device model and asset tag
  • Online / offline status and last check-in time
  • Key state: active, locked or erased
  • The signed erasure certificate
  • The device's address inside its own rental network
  • The audit trail of lock, revoke, erase and extend actions

Never collected — not even a column for it

  • File names and file contents
  • Browsing history
  • Installed application lists
  • Keystrokes and screenshots
  • Location
  • The name of the person using the device

The shared workspace folder does reach the server, but only as encrypted blocks. The key that opens them is made on a device and handed device to device. The server has never held it, so "we do not look at customer files" is not a policy here — it is arithmetic.
